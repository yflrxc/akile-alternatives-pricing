## FAQ

**Akile 的套餐为什么老缺货？**
多个来源都提到热门套餐经常缺货、需要蹲补货，官方通过 Telegram 频道（t.me/akile_notice）发布通知，但没有公开说明补货节奏。实用做法是把频道通知打开，或者直接选当期有货的档位，不必死等某一个型号。

**Lite 和 Pro 差在哪？**
Lite 是纯国际线路，不做中国大陆方向优化，胜在便宜；Pro 和优化系列做三网优化或提供原生 IP，价格通常贵一倍以上。以香港为例，Lite 从 ¥24.99 起，三网优化的 HKOPT-Lite 是 ¥59.99/月。如果你的访问主要来自国内，这个差价是值得的；如果只是拿来做落地解锁，Lite 够用。

**流量超了会怎样？**
官方轻量云页面写的是自动停机、流量不可重置。部分套餐的推广资料写的是降速到 10Mbps 并可付费重置。两套规则并存，下单页的说明才是准的。

**能不能换 IP？**
Akile 需要开工单换 IP，年付用户的换 IP 价格有下调，部分节点支持手动切换 IPv6。狗云弹性云可以在面板自助换 IPv4 和 IPv6，这一点上更省事。

**支付方式有哪些？**
Akile 支持支付宝、FPS 转数快、USDT 和信用卡，国内用户付款没有障碍。
